# Duplimancy

Website for applying custom card frames to lists of Magic: The Gathering cards, for on-screen previews and print-on-demand proxies (Commander, Premodern, Legacy, etc.; custom cubes later).

Status: design stage. No app code yet.

## Product decisions
- **No official frames.** Don't emulate WotC's frames; kits are original designs.
- **No official art.** Never fetch or host WotC/Scryfall card art. Art is user-uploaded or generated by Anhelo.
- **Rules text/stats are fine** to use (via Scryfall card data).
- **Large lists first.** The differentiator vs Card Conjurer is applying a frame to a whole decklist, not crafting one-off cards.
- No Adobe tools anywhere in the pipeline.
- Diffusion-model art generation dropped as YAGNI.

## Rendering
- **Editor/preview:** HTML + CSS. (The Vesuvan UI DSL is shelved.)
- **Print/export:** Typst → per-card SVG → sheet PDF. Don't maintain two competing renderers for final output.
- **Kits:** designer-uploaded Typst bundles implementing a Scryfall-shaped card schema. Untrusted code: compile in isolated worker processes with timeouts and memory caps.
- **Fonts:** shared library mirrored from google/fonts, pinned to a commit. Kits reference families by name; no kit-uploaded fonts.

## Docs
- `docs/kit-spec.md` — kit format, card schema, `@duplimancy/core`, render pipeline, upload validation, legal notes
- `docs/typst-primer.md` — Typst syntax crash course with a proxy-sheet example
- `docs/anhelo-design.md` — deterministic abstract art generator (seeding, layers, symmetry, palettes, faces, figures)

Read the relevant doc before working on kits, rendering or art generation. Update it when a decision changes.

## Determinism rules
- Same inputs → byte-identical output (kits and Anhelo alike).
- Anhelo: seeded PRNG (`xmur3` → `mulberry32`), never `Math.random`; one seed stream per concern; coordinates rounded to 0.1; pure SVG, no WebGL.

## Infrastructure
- Hosting: one DigitalOcean droplet (Ubuntu, 512 MB RAM + 2 GB swap). Keep builds light, or build in CI and ship artifacts.
- Domains: Porkbun.
- Login is SSH key only. Never commit keys, IPs or secrets.
